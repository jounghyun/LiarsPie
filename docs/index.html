🐜AntLab 개미연구소

라즈베리파이에서 24시간 돌아가는 업비트 코인·토스증권 국내 주식 자동매매 봇과, 폰·PC로 보는 모니터링 웹페이지예요.

정해 둔 전략대로 사고팔고, 과거 데이터로 "그때 이렇게 했다면?"을 계산해서 어떤 전략이 나았는지 보여줘요. 처음엔 모의투자(가상 돈)로 돌려 보고, 준비되면 실거래로 바꿔요.

⚠️ 투자 조언이 아니에요. 순위와 시뮬레이션은 "과거에 이렇게 했다면?"일 뿐, 앞으로도 그렇게 된다는 보장이 없어요. 실거래는 잃어도 괜찮은 금액으로만 하세요.

🍓 라즈베리파이

봇 2개(코인·주식)와 웹페이지가 24시간 돌아요

⇄

🏦 거래소

업비트(코인) · 토스증권(주식)에 시세를 묻고 주문을 내요

⇄

📱 나

웹페이지로 보고 고르고, 텔레그램으로 알림을 받아요

할 수 있는 것

  • 금고 + 계좌: 돈을 쉬는 돈(금고)과 여러 계좌로 나눠요. 계좌마다 종목 + 전략 + 손절선이 있고 자기 돈으로만 따로 사고팔아요. 같은 종목도 전략을 달리해 여러 계좌로 굴릴 수 있어요.
  • 전략 17가지: 유명한 매매 전략 13가지(해외 트레이딩뷰 인기 1·2위 지표 포함)와 주식 전용 4가지. 종목마다 매일 과거 데이터로 순위를 매겨요.
  • 살 때·팔 때 조합: 살 때와 팔 때 전략을 따로 고르고, 두 전략을 "그리고/또는"으로 묶을 수 있어요.
  • 연구 탭: 종목·기간을 고르면 전략 순위, 파이가 찾아 준 좋은 조합, 과거 매매 차트를 한 화면에서 봐요 (최대 8년).
  • 주식은 거래되는 시간 전체에서 사고팔아요 (넥스트레이드 종목은 08:00~20:00).
  • 텔레그램: 로그인 코드, 매매·오류 알림, 아침·마감 리포트, 명령어, 키 만료 알림, SSH 로그인 감시.
  • 정전·재부팅·통신 끊김에도 멈추지 않고, 다시 켜지면 거래소에 주문 결과를 물어서 이어서 해요.
  • 외부 라이브러리 없이 파이에 기본으로 있는 Python 3만 써요 (메모리 약 50MB).

순서

  1. 라즈베리파이 OS 굽기
    PC에 Raspberry Pi Imager를 설치하고 Raspberry Pi OS Lite (64-bit)를 골라요. 설정 편집에서 호스트 이름, 사용자 이름·비밀번호, (와이파이), SSH 사용, 시간대 Asia/Seoul을 정한 뒤 SD카드에 굽고 파이에 꽂아 켜요.
  2. 파이 주소 찾고 접속하기
    공유기 관리 화면(보통 192.168.0.1)에서 파이 IP를 찾아요 (예: 192.168.0.10). 주소 예약(고정 IP)을 해 두면 편해요. PC에서: 
    ssh <사용자 이름>@<파이 IP>
  3. 필요한 것 확인 
    python3 --version                    # 3.11 이상이면 돼요
sudo apt update && sudo apt install -y git
timedatectl                          # 시간대가 Asia/Seoul인지
    시간대가 다르면 sudo timedatectl set-timezone Asia/Seoul (매매 시각이 한국 시간 기준이에요).
  4. 코드 받고 설치 
    git clone https://github.com/jounghyun/LiarsPie.git ~/My_Pie
cd ~/My_Pie
bash deploy/install.sh                   # 서비스 3개 등록 + 시작 (코인 봇 · 주식 봇 · 웹페이지)
sudo loginctl enable-linger $USER        # 부팅할 때 자동으로 켜지게 (한 번만)
    받는 폴더는 꼭 ~/My_Pie여야 해요 (서비스가 이 폴더에서 돌아요). 잘 됐는지: 
    systemctl --user status mypie-bot mypie-web mypie-stock   # 셋 다 active (running)이면 정상
  5. 웹페이지 열기
    같은 공유기에 연결된 폰·PC 브라우저에서 http://<파이 IP>:8000. 처음에는 모의투자(가상 돈 100만 원)예요. 코인은 키 없이 바로 되고, 주식은 시세를 받으려고 모의투자도 토스증권 키가 필요해요.

처음 켜고 할 일

  1. PIN 바꾸기: 오른쪽 위 ⚙️에 빨간 점이 있으면 아직 기본 PIN 0000이에요. ⚙️ → 🔒 PIN에서 바꿔요. PIN은 계좌 만들기·이체·전략 바꾸기·실거래 전환·텔레그램 설정·키 넣기에 써요.
  2. 텔레그램 연결 (추천): 텔레그램을 보세요. 연결하면 웹페이지에 들어올 때 로그인 코드를 물어서 안전해져요.
  3. 계좌 하나 만들어 보기: 홈 탭 ＋ 코인 계좌 만들기 → 종목·판단 주기·전략·넣을 돈·PIN. 아니면 연구 탭에서 마음에 드는 전략을 찾아 ➕ 이 전략으로 계좌 만들기.
  4. (선택) IP 막기 버튼 준비: 텔레그램 SSH 알림의 🚫 IP 막기를 쓰려면 파이에서 한 번만: 
    sudo bash ~/My_Pie/deploy/firewall-setup.sh

업데이트

cd ~/My_Pie && git pull && bash deploy/install.sh

설정(config.toml)·키(.env)·기록(data/)은 그대로 남아요.

지우고 싶을 때 
systemctl --user disable --now mypie-bot mypie-web mypie-stock
rm ~/.config/systemd/user/mypie-*.service
rm -rf ~/My_Pie        # 키(.env)와 기록(data/)도 같이 지워져요

위쪽 칩과 버튼

  • 모의투자 / 실거래 칩: 지금 어느 쪽 돈으로 굴리는지. 실거래면 빨간색이에요.
  • 🎨: 화면 색 5가지 (1 라이트 퍼플 · 2 다크 트레이딩 · 3 화이트 블루 · 4 차분한 종이 · 5 벚꽃 핑크). 누르는 대로 바뀌고 폰·PC마다 따로 기억해요.
  • ⚙️: 텔레그램, 모의투자/실거래 전환, 거래소 키, PIN. 자세히
  • 코인 화면 위 숫자 칩(예: 📦 BTC · ETH)은 지금 계좌가 있는 코인이에요. 주식은 장 상태(예: 장 마감 · 애프터마켓 ~20:00)가 보여요.

금고와 계좌

코인과 주식이 같은 방식이에요. 실제 거래소 계좌(업비트, 토스증권)는 하나지만, 장부로 금고와 계좌 여러 개로 나눠 써요.

🏦 금고

쉬는 돈. 입금하면 여기로 들어와요. 봇은 이 돈을 쓰지 않아요

📦 계좌 ①

비트코인 · 4시간봉 · MACD 그리고 모멘텀

📦 계좌 ②

비트코인 2 · 일봉 · 터틀 트레이딩 · 손절 −10%

  • 계좌 = 종목 하나 + 전략(또는 조합) + 손절선(선택). 코인은 판단 주기(일봉·4시간·1시간·15분)도 골라요.
  • 계좌는 자기 돈으로만 사고, 팔면 그 돈은 계좌에 남아요 (금고로 가지 않아요). 다른 계좌 돈은 안 써요.
  • 같은 종목도 전략을 달리해 여러 개 만들 수 있어요 ('비트코인', '비트코인 2'처럼 이름이 붙어요). 코인 계좌는 최대 20개.
  • 돈이 없는 계좌는 사지 않고 지켜보기만 해요 (계획·순위는 계속 보여줘요).
  • 수익률은 "넣은 돈 합계" 기준이라 입출금·이체를 해도 틀어지지 않아요.

전략 바꾸기전략·손절선(코인은 판단 주기도)을 바꿔요. 들고 있는 건 팔지 않고 새 전략이 이어서 판단해요.
팔고 빼기전부 팔고, 다 팔린 뒤 판 돈과 남은 돈을 금고로 빼요. 계좌는 0원 지켜보기로 남아요. 다 팔리기 전에는 🧹 표시가 붙고 취소할 수 있어요.
지우기0원 계좌에만 나와요. 바로 지워요.
원래 있던 코인·주식 (실거래): 계좌가 있는 종목이면, 거래소에 원래 있던(또는 직접 산) 만큼을 그 종목의 바이앤홀드 계좌(예: '비트코인 · 원래 있던 코인')로 모아요. 전략이 '그냥 들고 있기'라 팔지 않고, 전략을 바꾸면 새 전략대로 사고팔아요. 계좌가 하나도 없는 종목은 건드리지 않아요.
모의투자와 실거래는 금고·계좌가 따로예요. ⚙️에서 바꾸고(코인·주식 따로), 바꿔도 아무것도 팔지 않아요. 모의투자 금고는 100만 원으로 시작하고, 개요의 금고 칸에서 가상 입금·출금을 할 수 있어요.

계좌 카드 읽는 법

홈 탭의 계좌 카드는 처음엔 접혀 있어요. 접힌 카드는 이름·주기·현재가·전략 줄과 계좌 금액(수익률)만 보여요. 누르면 펼쳐지고(그 기기에 기억), 차트도 그 종목으로 바뀌어요.

  • 전략 이름 색: 전략마다 혼자 판단했다면 지금 사자(빨강)인지 팔자(파랑)인지예요. 조합은 조건이 다 맞아야 사요 (예: 'MACD 그리고 모멘텀'에서 모멘텀이 파랑이면 아직 안 사요).
  • 이 전략 vs 그냥 들고 있었다면: 같은 돈을 같은 때 넣고 사서 그냥 들고만 있었다면 얼마였을지와 나란히 보여주고, 한 줄로 판정해요.
  • 계좌 금액 / 넣은 돈: 들고 있으면 그 안의 코인·주식, 현금(살 돈), 평가 손익도 나와요.
  • 확정 손익: 판 매매로 확정된 손익이에요 (수수료·세금 뺀 뒤). 이 계좌의 승패와 번 돈·잃은 돈.
  • 수익 그래프: 첫 매매부터 이 전략(실선)과 그냥 들고 있었다면(점선). ▲산 곳 ▼판 곳, 들고 있던 때는 색칠돼요. 그래프에 마우스를 대거나 손가락으로 옆으로 밀면 그때의 가격과 수익률, 사고판 기록이 나와요.
  • 주식 카드에는 KRX·NXT 또는 KRX가 붙어요 (어느 거래소에서 거래되는지). 펼치면 🕗 줄에 사고파는 시간이 나와요.

전략 17가지

코인·주식 공통 13가지 + 주식 전용 4가지예요. 🌍는 해외 최대 차트 커뮤니티 TradingView의 역대 인기 순위예요.

전략사는 때파는 때잘 맞는 장
변동성 돌파가격이 오늘 시가 + 어제 변동폭 × 0.5를 넘을 때다음 날 시작하루 단위 급등

각 전략을 쉽게 풀어보면
  • 변동성 돌파: "오늘 시가 + 어제 움직인 폭의 절반"을 넘으면 오르는 날로 보고 사고, 다음 날 시작에 무조건 팔아요. 큰 하락을 피하기 쉽지만 가짜 돌파가 잦은 횡보장에서는 자주 손해를 봐요. (래리 윌리엄스)
  • 변동성 돌파 + 이동평균: 위와 같지만 상승 추세(어제 종가가 5일 평균 위)일 때만 사요. 하락장에서는 쉬어서 손실을 줄이는 대신 반등 초입을 놓칠 수 있어요.
  • 이동평균 골든크로스: 5일 평균이 20일 평균 위면 들고 있다가 아래로 내려가면 팔아요. 큰 추세를 길게 타지만 신호가 늦어요.
  • RSI 역추세: 최근 14일 오른 힘과 내린 힘을 0~100으로. 30 아래면 사고 70 위면 팔아요. 계속 떨어지는 장에서는 손실이 커질 수 있어요.
  • 볼린저 밴드: 20일 평균 위아래로 평소 흔들리는 폭만큼 띠를 그려서, 띠 아래로 떨어지면 사고 평균선 위로 오면 팔아요. 박스권에 강해요.
  • MACD: 12일 평균과 26일 평균의 차이가 그 차이의 9일 평균보다 크면 들고 있어요. 전환을 빨리 잡지만 횡보장에선 수수료가 쌓여요.
  • 터틀 트레이딩: 20일 최고가를 넘으면 사고 10일 최저가를 깨면 팔아요. 작게 자주 잃고 가끔 크게 버는 구조예요.
  • 모멘텀: 오늘 가격이 30일 전보다 높으면 들고, 낮으면 팔아요.
  • 스토캐스틱: 최근 14일 가격 범위에서 지금 위치를 0~100으로 봐요. 바닥권에서 올라서면 사고 꼭대기권에서 꺾이면 팔아요.
  • 스퀴즈 모멘텀: 가격이 좁게 갇혀 힘을 모으다가 풀리면서 오르는 힘이 커지면 사요. 터지는 움직임을 잘 잡지만 일찍 팔 때가 많아요.
  • 스마트 머니 (시장 구조): 양옆 5일보다 높은 꼭짓점을 고점, 낮은 바닥을 저점으로 잡아, 고점을 넘으면 사고 저점을 깨면 팔아요.
  • 슈퍼트렌드: 평균 흔들림(ATR)의 3배만큼 떨어진 곳에 선을 긋고, 그 선을 넘나들 때 사고팔아요. 큰 추세에 강해요.
  • 바이앤홀드: 판단 없이 사서 계속 들고 있어요. 다른 전략이 "그냥 들고 있기"보다 나은지 보는 기준이에요.
순위는 이렇게 매겨요: 하루 한 번 계좌의 종목·주기마다 전략을 전부 과거 데이터로 굴려 봐요 (백테스트). 코인은 수수료 0.05%, 주식은 수수료 0.015% + 팔 때 증권거래세 0.2% + 매매마다 호가 한 칸을 반영해요. 전략 고르는 칸의 목록이 이 순위대로 나와요.

조합

계좌마다 살 때와 팔 때를 따로 골라요. 한쪽에 전략을 하나 또는 둘까지 넣을 수 있어요.

하나라도 신호가 나면

  • 전략 칸에서 ＋ 하나 더로 두 번째 전략을 넣고 가운데 그리고/또는을 골라요. ✕로 다시 하나로.
  • 안 들고 있을 때는 살 때 쪽만, 들고 있을 때는 팔 때 쪽만 봐요.
  • 사는 건 새 신호일 때만: 살 때 쪽이 '안 삼 → 삼'으로 바뀐 때 사요. 그래서 조합으로 바꾸면 새 매수 신호를 기다려요.
  • 파는 건 상태로: 팔 때 쪽이 '안 들고 있음'이면 팔아요 ("그리고"면 둘 다, "또는"이면 하나라도).
  • 한 봉 시작에 판 계좌는 그 봉 시작에 다시 사지 않아요 (사고팔기만 반복하지 않게).

손절선 (선택, 1~50%)

  • 산 값(수수료 포함 평단)보다 정한 %만큼 떨어지면 전략과 상관없이 바로 팔아요. 산 직후에도 지켜요.
  • 손절로 판 뒤에는 매수 신호가 한 번 꺼졌다가 다시 켜질 때 다시 사요 (손절이 소용없어지지 않게).
  • 계좌 카드에 🛑 손절선과 손절 가격이 보이고, 손절 뒤에는 "손절 뒤 쉬는 중"으로 나와요.

연구 탭 (시뮬레이션)

"과거에 이렇게 사고팔았다면?"을 계산해요. 위에서부터 ① 고르기 → ② 순위 → ③ 자세히 순서예요 (코인·주식 같아요).

종목 · 판단 주기(코인) · 과거 기간 · 손절선을 한 번만 골라요. 아래 순위와 자세히 보기가 다 이걸 따라가요. 기간은 1주~8년이에요 (15분봉은 3년까지).

  • 코인은 📈 곡선으로 비교(상위 3개 + 고른 전략 + 바이앤홀드)를 펼쳐 볼 수 있어요.

③ 자세히

  • 이 전략 vs 그냥 들고 있었다면 표: 100만 원이 얼마가 됐을지 · 수익률 · 최대 낙폭, 그리고 "그냥 들고 있기보다 2.1%p 더 벌었어요" 같은 한 줄 판정.
  • 사고판 횟수·이긴 비율·이 기간 순위·마지막 상태, 가격 차트 위 매수▲·매도▼와 들고 있던 구간, 내 돈 곡선.
  • 💡 이 전략은?: 고른 전략들의 설명.
  • ✏️ 살 때·팔 때 직접 고르기: 조합을 직접 만들어 볼 수 있어요 (평소엔 접혀 있어요).
  • ➕ 이 전략으로 계좌 만들기:
    • 똑같은 계좌가 있으면 그 카드를 보여줘요.
    • 같은 종목 계좌가 있으면 그 계좌 전략을 이걸로 바꿀지, 새 계좌를 따로 만들지 물어봐요. 바꾸기를 고르면 그 계좌의 '전략 바꾸기' 칸이 채워져 열리고, PIN을 넣어야 실제로 바뀌어요.
    • 없으면 계좌 만들기 칸을 채워요 (금액·PIN을 넣어야 만들어져요).

긴 기간 계산

  • 봉이 1,500개 넘거나 3년 이상이면 파이가 따로 계산해요. 1분이 넘을 것 같으면 예상 시간을 보여주고 계산 시작을 눌러야 시작해요. 진행률·남은 시간·■ 멈춤이 있고 화면을 닫아도 계속해요.
  • 모자란 과거 봉은 먼저 받아요. 계산은 매매를 방해하지 않게 우선순위를 낮춰 코어 수 − 1개로 해요.
  • 결과는 그날 하루 저장돼서 다시 열면 바로 나와요. 계산 작업은 한 번에 하나예요.
  • 상장한 지 얼마 안 된 종목은 있는 만큼만 계산하고 "※ 있는 만큼만 계산했어요"라고 알려 줘요.
한 기간에서 1등인 조합이 다른 기간에서도 잘 되는지 꼭 확인하세요. 많이 비교해서 고를수록 과거에만 우연히 맞은 조합이 뽑히기 쉬워요. 👍 두 절반이 붙은 걸 먼저 보세요.

🔍 좋은 조합 찾기

  • ② 순위의 🔍 조합도 찾아보기나 🔁 다시 찾기로 시작해요. 종목·주기·기간은 ① 고르기 그대로예요.
  • 그 기간 단일 전략 상위 6개를 살 때·팔 때에 하나 또는 둘(그리고·또는)로 섞어요: 한쪽 36가지 × 다른 쪽 36가지 = 1,296가지.
  • 기간은 1·2·3·5·8년 (15분봉은 2년까지). 파이 3B에서 비트코인 4시간봉 3년이 약 30초, 8년이 약 1분 30초 걸렸어요.
  • 진행률·남은 시간·멈춤이 ② 순위 아래에 나오고, 끝나면 순위에 바로 들어가요. 1분 넘게 걸린 계산은 텔레그램으로도 1~5위를 보내요.
  • 결과는 최근 5개가 저절로 남고, ☆ 저장하면 50개까지 남아요. 지난 조합 찾기에서 고르면 그 조건으로 바뀌어 다시 볼 수 있어요.
  • 예전에 찾은 결과면 "순위는 ○○까지 데이터로 찾은 거라 자세히 보기(오늘까지)와 숫자가 조금 달라요"라고 알려 줘요. 🔁 다시 찾기로 맞추면 돼요.
  • 손절선을 켜면 조합은 빼고 보여줘요 (조합 찾기는 손절선 없이 계산해요).

  • 그 뒤 거래되는 시간에는 10초마다 돌파 매수·이탈 매도·손절선·팔고 빼기를 해요. 장이 끝난 뒤에도 손 놓고 있지 않아요.
  • 주문을 모아 한 가격에 한꺼번에 체결하는 단일가 시간(08:50~09:00, 15:20~15:40)에는 새 주문을 내지 않아요.
  • 장 밖에서 한 매매는 기록에 '· 프리마켓', '· 애프터마켓'이 붙어요. 장 밖은 거래가 적어 값이 덜 좋을 수 있어요.
  • 장 시간은 토스증권 장 달력으로 매일 확인하고, 종목이 NXT에 들어왔는지·ETF인지도 매일 확인해요. 휴장일은 쉬어요.

일봉과 계산

  • 판단·순위·시뮬레이션·조합 찾기는 모두 그날 거래가 다 들어간 일봉(KRX·NXT 통합)으로 해요. 봇이 사고파는 시간과 같아야 결과가 맞아서예요.
  • NXT가 생기기 전 일봉은 원래 KRX 거래뿐이라, 같은 방식으로 과거 전체를 계산해도 예전과 같아요. KRX만 되던 종목이 NXT에 새로 들어오면 그날부터 일봉이 넓어질 뿐이에요.
  • 계획의 '오늘 시가'는 그날 첫 거래 가격이에요 (NXT 종목은 08:00).

주문은 이렇게 내요

  • 그 순간의 호가로: 살 때는 가장 싼 매도 호가, 팔 때는 가장 비싼 매수 호가에 지정가를 내요 → 바로 체결되는 값이에요.
  • 10초 안에 다 안 되면 남은 건 취소하고, 다음 확인 때 그때의 호가를 새로 받아서 다시 내요. 폭등·폭락 때 처음 값에 묶여 있지 않게요.
  • 사는 쪽: 호가가 계획 가격보다 1% 넘게 비싸면 쫓아 사지 않고 기다려요. 하루 첫 거래 매수는 5분 동안 다시 해 보고, 안 되면 그날은 건너뛰고 알려 줘요.
  • 파는 쪽: 매도 신호·손절·팔고 빼기는 빠져나오는 게 목적이라 다 팔릴 때까지 그때 호가로 다시 내요.
  • 매매마다 계획 가격을 같이 적어서 🧾 기록 탭에 체결 오차(+ = 손해)와 평균(호가 몇 칸)을 보여줘요.
  • 모의투자도 같은 호가로 체결됐다고 쳐서 실제와 비슷해요.
호가 한 칸은 가격대마다 달라요. 예를 들어 삼성전자(20만 원대)는 500원(약 0.24%)이라, 사고팔 때 한 칸씩만 밀려도 왕복 0.5% 가까이예요. ETF는 5원이라 거의 상관없어요. 그래서 시뮬레이션도 매매마다 한 칸 불리하게 계산해요.

실거래 시작하기

실거래로 바꾸면 진짜 돈으로 주문이 나가요. 모의투자로 충분히 지켜본 뒤, 처음엔 작은 금액으로 시작하세요.

코인 (업비트)

  1. 업비트 API 키를 넣고, 업비트에 원화를 입금해요 (굴릴 금액보다 0.5% 정도 더).
  2. ⚙️ → 🪙 코인 계좌 → 실거래 → "실제 돈으로 주문이 나간다는 걸 이해했어요" 체크 → PIN → 계좌 바꾸기. 위쪽 칩이 빨간 실거래가 되면 정상이에요. 업비트 원화는 금고로 들어와요.
  3. 코인 계좌를 만들고 금고에서 돈을 넣어요. 계좌로 옮긴 돈으로만 사고팔아요.
  4. 그만하려면 계좌마다 팔고 빼기 → 필요 없으면 지우기. 모의투자로 바꾸는 것만으로는 아무것도 팔지 않아요.

주식 (토스증권)

  1. 토스증권 키를 넣으면 1분 안에 주식 봇이 모의투자로 시작해요.
  2. 지켜본 뒤 ⚙️ → 📈 주식 계좌 → 실거래 → 체크 → PIN → 계좌 바꾸기.
토스증권 API에는 모의투자 서버가 없어서, 실거래로 바꾸면 첫 주문부터 진짜예요.

업비트 API 키 받기

  1. PC에서 업비트 로그인 → 마이페이지 → Open API 관리.
  2. 권한은 자산조회 · 주문조회 · 주문하기만. 출금 권한은 절대 주지 마세요 (키가 털려도 돈을 못 빼가게).
  3. 허용 IP에 집 공인 IP를 넣어요 (공유기 관리 화면의 "외부 IP"). 집 IP가 바뀌면 여기만 고치면 돼요.
  4. 본인 인증 후 Access Key·Secret Key가 나와요. Secret Key는 한 번만 보여줘요. 카톡·메일로 보내지 마세요. 키는 1년이면 만료되고 연장이 안 돼요.
  5. 웹페이지 ⚙️ → 🪙 코인 계좌 → 🔑 업비트 키 넣기에 두 키와 PIN → 연결해 보고 저장. "연결 성공!"과 원화 잔고·만료일이 나오면 돼요. 집 와이파이에서만 넣을 수 있어요.

토스증권 키 받기

  1. PC에서 토스증권 웹(WTS) → 설정 → Open API에서 Client ID · Client Secret 발급.
  2. 같은 화면 허용 IP 관리에 집 공인 IP 등록.
  3. 토스증권 앱에서 투자자지시 거래소를 통합(SOR)으로 (아니면 주문이 거절돼요).
  4. 웹페이지 ⚙️ → 📈 주식 계좌 → 🔑 토스증권 키 넣기에 두 값과 PIN → 연결해 보고 저장 (계좌가 여러 개면 고르는 칸이 나와요).

안전장치

🏦 금고 돈은 안 써요

실거래로 바꾸면 거래소 돈이 전부 금고로 들어오고, 봇은 계좌로 옮긴 돈으로만 사요.

🔌 끊겨도 이어서

주문마다 고유 번호를 붙여서, 도중에 끊기면 다시 켜질 때 거래소에 결과를 물어 장부를 맞추고 이어서 해요. 같은 주문이 두 번 나가지 않아요.

🌐 집 IP 변경 감지

10분마다 집 공인 IP를 확인해서, 거래소 허용 IP와 달라지면 경고해요. 허용 IP만 고치면 자동으로 다시 주문해요.

🔑 키 만료 알림

업비트 키 만료 30·14·7·3·1일 전에 텔레그램으로 알리고, 만료되면 갱신 방법까지 보내요.

🔒 PIN

바꾸는 건 모두 PIN이 필요해요. 처음은 0000이니 꼭 바꾸세요. 5번 틀리면 10분 잠겨요.

🗝️ 키 보관

키는 파이의 ~/My_Pie/.env에만 있어요 (깃허브에 안 올라감). 화면에 다시 보이지 않아요.

보안 체크리스트

  • ☐ PIN 0000을 내 PIN으로 바꾸기
  • ☐ 텔레그램 연결해서 로그인 코드 켜 두기
  • ☐ API 키에 출금 권한 주지 않기, 허용 IP 등록하기
  • ☐ SSH는 공개 키 로그인을 쓰고 비밀번호 로그인은 끄기 (PasswordAuthentication no)
  • ☐ .env, data/, config.toml은 다른 사람에게 주지 않기

텔레그램

연결하는 법

  1. 텔레그램에서 @BotFather에게 /newbot을 보내 이름과 아이디(끝이 bot)를 정하면 봇 토큰을 줘요.
  2. 웹페이지 ⚙️ → ✈️ 텔레그램에 토큰과 PIN을 넣고 연결 시작.
  3. 화면에 나온 내 봇에게 아무 메시지나 보내면 자동으로 연결돼요.

되는 것

  • 웹페이지 로그인: 들어오면 로그인 코드(기본 2자리)가 42 (192.168.0.10)처럼 기기 IP와 함께 와요. 코드를 넣거나 ✅ 들여보내기를 누르면 열려요. 🙅 거절, 집 밖 IP면 🚫 이 IP 막기도 와요. 로그인은 최대 24시간 기억해요.
  • 알림: 매수·매도 체결(손절 포함), 오류, 집 IP 변경, 입금 감지, 설정 변경, 봇 재시작, 키 만료. 파이가 85°C를 3분 넘게 넘거나 전압이 모자라면 알려요.
  • 리포트: 코인은 아침 09시 매매 뒤, 주식은 장 마감 뒤.
  • SSH 로그인 감시: 집 밖에서 로그인 성공하면 바로 알리고, 실패는 낮 12시·밤 12시에 모아서 IP별로 알려요. 🚫 IP 막기를 누르면 파이 방화벽이 그 IP를 막아요 (집 안 IP는 안 막아요).

집 밖에서 보기 (선택)

  1. 주소 예약: 파이 IP가 바뀌지 않게 공유기에서 고정해요.
  2. DDNS: 집 공인 IP는 가끔 바뀌어요. DDNS를 켜면 내이름.iptime.org 같은 바뀌지 않는 주소가 생겨요 (ipTIME: 고급 설정 → 특수기능 → DDNS 설정).
  3. 포트포워딩: 내부 IP는 파이, 내부 포트는 8000, 외부 포트는 8000이 아닌 번호(예: 18000)가 덜 찔려요 (ipTIME: 고급 설정 → NAT/라우터 관리 → 포트포워드 설정).
  4. 밖에서 http://내이름.iptime.org:<외부 포트>로 들어가요.
포트를 열기 전에: 텔레그램 연결(안 하면 누구나 볼 수 있어요), PIN 바꾸기. 웹페이지는 https가 아니라 공용 와이파이에서는 조심하세요. SSH(22번)는 열지 않는 게 좋아요.

자주 쓰는 명령

파이에서 cd ~/My_Pie 한 다음:

systemctl --user status mypie-bot mypie-web mypie-stock   # 상태
journalctl --user-unit mypie-bot -f             # 봇 로그 실시간 (주식은 mypie-stock)
systemctl --user restart mypie-bot mypie-web mypie-stock  # 설정 파일을 바꾼 뒤 재시작
python3 -m mypie.pin                            # PIN 새로 정하기
python3 -m mypie.keys                           # 업비트 키 등록/변경
python3 -m mypie.keys --check                   # 업비트 키 확인·만료일
python3 -m mypie.toss                           # 토스증권 키 등록/변경
python3 -m mypie.toss --check                   # 토스증권 키 확인
python3 -m mypie.telegram --code                # 텔레그램이 안 될 때 로그인 코드
python3 -m mypie.telegram --off                 # 텔레그램 연결 끊기
python3 -m unittest discover -s tests -v        # 테스트 (실제 주문·텔레그램 없음)

세부 숫자(전략 파라미터, 순위 기준, 로그인 유지 시간 등)는 config.toml에서 바꿔요. 항목 설명은 config.example.toml에 있어요.
